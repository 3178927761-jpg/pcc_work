# Python 循环调试 · 6 天进阶版

每天只做 **1 个文件**，大约 25–35 分钟。  
这一版不是“多塞几个 bug”，而是让状态更多：每组题仍然只追 **一个根因**，但需要同时观察 2–3 个变量，部分题目要跑两组数据才会暴露问题。

## 一、日程

| 天 | 文件 | 循环/结构 | 重点观察 |
|---|---|---|---|
| Day 1 | `Day1_for_有效平均分.py` | `for` + `continue` | `score`、`total`、`count` |
| Day 2 | `Day2_嵌套while_数根.py` | 嵌套 `while` | `n`、`total` |
| Day 3 | `Day3_嵌套for_全及格小组.py` | 嵌套 `for` + 标志位 | `r`、`c`、`all_pass` |
| Day 4 | `Day4_for改字典_打折.py` | `for` 遍历字典并改值 | `name`、`price`、`prices[name]` |
| Day 5 | `Day5_类与while_账户手续费.py` | 类 + 方法 + `while` | `amount`、`self.fee`、`self.balance` |
| Day 6 | `Day6_类组合与for_荣誉名单.py` | 类组合 + `for` | `student.name`、`student.score`、`names` |

> 一天只发一个文件，不要一次发完。  
> 第 5、6 天会出现两层方法调用，要连续按 `F11` 进入；先确保 Day 1–4 的单步已经熟练。

## 二、每天固定五步

1. **先运行**：看现在输出什么，不要改代码。
2. **先预测**：在纸上写“第一轮、第二轮，各变量应该是多少”。
3. **下断点**：在循环那一行点红点，按 `F5` 启动。
4. **单步看**：`F10` 一行一行走，把变量面板里的值和你预测的对照。
5. **再修复**：找到“第一处和预期不一样”的地方，只改那里，重新运行。

进阶版多一步：**如果代码给了两组数据，先分别跑，确认哪一组坏、哪一组好**。  
“只有第二组坏”通常意味着边界条件或状态没有重置，不要只盯着第一组。

## 三、VS Code 调试卡

先装 Python 扩展，然后打开整个文件夹（不要只打开单个 `.py`）。

| 操作 | 快捷键 | 用途 |
|---|---|---|
| 打断点 | 在行号左侧点一下 / `F9` | 让程序停在这一行之前 |
| 启动调试 | `F5` | 不要用右上角的“Run”，那个不会停 |
| 单步跳过 | `F10` | 执行这一行，不进入函数 |
| 单步进入 | `F11` | 进入这一行调用的函数/方法 |
| 单步跳出 | `Shift + F11` | 从当前函数返回调用处 |
| 停止 | `Shift + F5` | 结束调试 |
| 看变量 | 左侧 `VARIABLES` → `Locals` | 展开 `self` 可以看到对象属性 |
| 加监视 | `WATCH` → `+` | 输入 `i`、`total`、`self.balance`、`prices[name]` |
| 看调用链 | 左侧 `CALL STACK` | 能看出“谁调用了谁” |
| 临时算表达式 | 下方 `DEBUG CONSOLE` | 输入 `scores`、`self.balance` 回车 |

小技巧：断点可以只停在某一次循环。右键红点 → `Edit Breakpoint` → 输入条件，例如 `i == 2`、`student.name == "小红"`。

### 用别的工具

- **PyCharm**：行号旁点红点；`Shift+F9` 调试，`F8` 单步跳过，`F7` 单步进入，`Shift+F8` 跳出，`Alt+F8` 计算表达式。
- **Thonny**：`Run → Debug current script`；`F6` 单步跳过，`F7` 单步进入，变量在右侧 `Variables`。
- **IDLE 没有真正的图形调试器**：可以用 [Python Tutor](https://pythontutor.com/python-debugger.html) 粘贴代码单步看。
- **想练 Python 自带的 pdb**：在要停下的地方写一行 `breakpoint()`，正常运行程序，会进入 `(Pdb)` 提示符。常用命令：`n` 下一行、`s` 进入函数、`c` 继续、`p 变量名` 打印、`l` 看附近代码、`q` 退出。

## 五、三条规则

1. 不改 `main()` 里的测试数据和 `print` 文案，只修 bug。
2. 一次只改一个地方；改完立刻重新运行全部测试数据。
3. 修好后，用一句话说出“为什么会错”，说不出来就还没真的修好。

## 六、卡住了怎么办

- 先看文件末尾的“提示”，从提示 1 开始，不要直接看提示 2。
- 还是卡住，就把循环**只跑前两轮**：断点条件设成 `i == 1` 或 `student.name == "小红"`，看第二轮结束时变量是多少。
- 最后再问：把“哪组数据 / 预期值 / 实际值 / 第一个异常值”四句话发出来，比直接问“这题怎么改”更容易得到有效帮助。
